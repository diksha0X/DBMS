2. Prove Entity Integrity

Entity integrity means:

Primary key cannot be NULL
Primary key must be unique
Check NULL
INSERT INTO Customer
VALUES (NULL, 'Test', 'Test', 'AA', 1234567);

Result: Error because Cust_id is a primary key.

Check duplicate
INSERT INTO Customer
VALUES ('A01', 'Test', 'Test', 'AA', 1234567);

Result: Error because A01 already exists.

Same applies to Mv_no in Movie because it is also a primary key.

3. Prove Referential Integrity

Movie.Cust_id is a foreign key referencing Customer.Cust_id.

Try:

INSERT INTO Movie
VALUES (11, 'A99', 'Test', 'AB', 150);

Result: Error because A99 does not exist in Customer.

Therefore, referential integrity is maintained.
